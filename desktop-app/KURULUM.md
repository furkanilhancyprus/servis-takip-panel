# Servis Takip Panel - Masaustu Uygulamasi

## Calisma Mantigi

- Uygulama `https://servistakippanel.com` web panelini masaustu penceresinde acar.
- Web paneldeki tum ozellikler masaustu uygulamada ayni sekilde kullanilir.
- Internet baglantisi gerektirir.
- Masaustu uygulamasi tek urun olarak web panel istemcisi seklinde paketlenir.

## Derleme

```bash
cd desktop-app
npm install
npm run dist
```

Cikti:

```text
dist/ServisTakipPanel-1.0.0-Kurulum.exe
```

Landing sayfasindaki indirme dosyasi:

```text
../downloads/ServisTakipPanel-Kurulum.exe
```
